# TPS AI Gateway 0.1.4

This patch makes gateway settings persistence merge-safe and durable under overlapping edits.

## Changes

- Reloads current plugin data and applies only locally changed fields, preserving synchronized, unknown, and higher-schema fields.
- Preserves explicit provider subsets and intentionally empty text values.
- Retains rapid reverts, waits for durable state, lets queued newer values supersede failures, and reconciles live edits made during I/O.

## Compatibility and validation

- Minimum Obsidian: 1.12.0; desktop and mobile supported; no manual migration.
- Focused gateway/settings tests and full declared suite: 15/15 passed; TypeScript and diff checks passed.
- A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; AI Gateway registered normally and its runtime-owned `data.json` hash remained unchanged.
- Live provider calls and credentials remain outside this persistence regression pass.
