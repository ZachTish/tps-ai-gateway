# TPS AI Gateway 1.0.0

This major release removes the synced-file AI transport. Direct explicit OpenAI, Gemini and Ollama requests remain. Minimum Obsidian: 1.12.0.

## Immediate changes
- No startup queue scan, create/modify listeners, 30-second poll, delayed queue timer, job claiming, request/result writes, completion notifications, or Apple URL handoff.
- Apple is explicitly unavailable; it never silently selects a backup. Durable jobs and missing-provider queue fallback fail before vault work.
- Removed request-folder and Apple enable controls. Existing queue files, device state, SecretStorage references and unknown settings remain untouched. Legacy plaintext keys are no longer automatically migrated; configure a secret explicitly if needed.
- Unload during settings loading cannot register a late API, command or settings tab.

Runtime reduction: 18 additions and 571 deletions, net -553 lines. Queue service 1→0; queue create/modify listeners 2→0; startup scan 1→0; periodic queue poll and delayed scan owners 2→0; file request/result/claim writers removed. Explicit direct provider timeouts are retained.

## Validation
37 tests passed with no failures/skips, followed by a separate TypeScript/production build and stable test-vault deployment. Direct provider transports are mocked; no external inference was sent. Tests cover provider shapes, image/grounding constraints, schemas, guarded capabilities, concurrent settings saves, 20 settings loads with zero credential or storage writes, inert field preservation, retirement errors and the reproduced unload race.

The final 1.0.0 runtime was loaded in Obsidian Plugin Test Vault. Installed API checks returned appleIntelligence=false and explicit Apple/durable retirement errors. Native Controller → Connections → AI displayed the unavailable route, preserved backups, direct-provider guidance and one Diagnostics disclosure; no setting was changed. Gateway was unloaded afterward and its original disabled state restored; the public API was removed.

Integrated foreground test-vault evidence (five each): warm reload current median/worst 6066.2/7142.1 ms; cleaned 6084.7/7143.5 ms; TPS disabled 6360.5/6755.1 ms. Long tasks: 14/15/10 respectively. Sequential samples show no >10% or 50 ms median regression; startup variability prevents a claim of improvement. Navigation current 897.2/1134.5 ms; cleaned 838.9/892.9 ms; disabled 427.3/529 ms. These are combined-plugin measurements, not AI-specific attribution or production cold-start results. Integrated idle/typing/Sync/settings/Finance checks observed zero TPS maintenance writes. Physical iPhone acceptance is unverified.

## Rollout and rollback
Tested in the test vault and ready for the user's BRAT pull. Production was not installed or reloaded. Existing pending jobs are preserved but no longer processed. Old durable-job consumers must update (Health cleanup removes those callers). This release does not configure TishOS. Downgrading can reactivate workers and replay preserved jobs; stop owners and review state first. Notes are never rolled back automatically.
