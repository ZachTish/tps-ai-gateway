# TPS AI Gateway 1.1.1

Apple Shortcuts requests now complete in Obsidian when shortcut or vault names contain spaces. Native URLs use percent-encoded spaces; callback ownership checks the receiving vault because Obsidian consumes its routing parameter. Apple's whole JSON code fences are accepted before schema validation; extra prose and malformed responses still fail. Cancellation, bounded input/output, timeout and no-backup-after-handoff behavior are unchanged.

Gemini CLI policy now uses its supported isolated user-settings location, preserving unrelated CLI preferences and login state. It no longer supplies user-owned files as root-owned system settings. The provider picker and guidance correctly identify Gemini CLI as requiring an eligible Code Assist work account: current personal Google AI subscriptions have moved to Antigravity, which this release does not integrate. OAuth success alone is not proof of model access.

No persisted schema changes, settings migration, note writes, vault scans, background jobs or credential adoption. Minimum Obsidian version remains 1.12.0. Settings remain one flat page with one Advanced disclosure, native labelled controls, scoped responsive CSS and no requests on opening settings.

- All eight provider states retain their controls, labelled provider selector and one disclosure with no nesting. Changed Apple and Google guidance inspected in reloaded native settings.
- Test settings SHA-256 remained `06ae53f8fe2cdf0ab8fa1ab81c16e7b301990f8f34fb53147d69a4f021861291`; original disabled state restored and Sync remained disabled.

## Limits and handoff

Tested in the Mac test vault and available for the user's BRAT pull. Direct production deployment is recorded separately; publication alone is not a production or phone acceptance claim. Physical iPhone/iPad acceptance is unverified. Apple requests use a foreground handoff and may require Obsidian/Shortcuts permission prompts.

Authenticated Grok inference is unverified while its new account-access consent is pending. The current personal Google account completed OAuth but Gemini CLI rejected its eligibility; it is not a working consumer subscription connection. Antigravity was investigated but is not integrated. Other network adapters use mocked transports in the regression suite unless previously documented separately.
