# TPS AI Gateway 0.2.3

## Intent

Reduce recurring Controller queue-scan work without changing any released queue, provider, notification, settings, or public API behavior.

## Changes

- Resolve `_assets/TPS AI Queue` through Obsidian's supported folder API and recursively snapshot only its Markdown descendants.
- Stop enumerating and filtering every Markdown file in the vault on startup, queue events, and the 30-second reconciliation interval.
- Preserve nested queue jobs, public traversal order, one-at-a-time reads, two-pass coalescing, Controller authority checks, per-file failure isolation, retained-job expiry, provider fallback, and notification behavior.
- Treat a missing queue folder or an exact-path file collision as the existing empty-queue state. No whole-vault fallback, cache, alternate read, retry, listener, timer, persisted state, or migration was added.

## Before/after evidence

The same benchmark compiled and exercised the exact released 0.2.2 service and the 0.2.3 candidate with 100,000 unrelated Markdown files, one queue job, ten warmups, and 100 measured scans.

- Queue read paths remained identical and maximum read concurrency remained one.
- 0.2.2 called whole-vault Markdown enumeration 100 times and inspected 10,000,100 entries.
- 0.2.3 made zero whole-vault calls and visited 100 queue-subtree entries.
- Median synthetic scan time changed from 3.432 ms to 0.0029 ms; p95 changed from 3.793 ms to 0.0035 ms.

These timings isolate enumeration overhead; provider transport and queue-job processing latency are unchanged.

## Validation

- Focused queue regressions: 9/9 passed.
- Final 0.2.3 declared suite: 24/24 passed.
- TypeScript and the required separate production-mode build passed.
- The final artifacts deployed byte-identically only to the registered Obsidian Plugin Test Vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**, and the `TPS AI Gateway: Validate provider chain` command was present without invoking it, linking credentials, or sending a provider request.
- Runtime `data.json` remained byte-identical at SHA-256 `6cfa72987ad1b642a8368b6c342a0b22d39fcab83af988b13e77c9398baee42b`.
- Production was not accessed or modified.

## Compatibility and limitations

- Minimum Obsidian version remains 1.12.0; `getFolderByPath` and `Vault.recurseChildren` are public Obsidian APIs available below that minimum.
- No settings, queue-format, credential, or data migration is required.
- Remote jobs still rely on ordinary vault sync and retain the existing polling, claim-recovery, timeout, retention, and 30-second reconciliation behavior.
- Provider fallback is intentional released behavior and remains unchanged.
