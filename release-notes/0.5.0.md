# TPS AI Gateway 0.5.0

TPS AI Gateway 0.5.0 adds a dedicated compatibility path for Google-hosted Gemma so TPS Health and other callers can use a no-token-charge Google model without sending it Gemini-only structured-output fields.

## User-visible changes

- New installations default the existing Google AI provider to `gemma-4-26b-a4b-it`.
- The settings surface now labels the shared credential and model fields **Google AI API key** and **Google AI model**. Existing SecretStorage references, saved model choices, and the public `gemini` provider ID are preserved.
- Hosted Gemma receives the caller's exact schema as an explicit instruction, with attached images placed before the related text. Results are schema-validated on the device.
- A complete JSON value returned inside a Markdown fence or brief surrounding text is normalized safely. Invalid or schema-mismatched output receives one corrective retry, then fails closed.
- Google Search grounding now reports a clear model incompatibility before transport when hosted Gemma is selected. Select a Gemini model for grounded web research.

## Compatibility and migration

- Minimum Obsidian version: 1.12.0.
- This is a backward-compatible feature release. No settings or queue migration is required.
- Existing Gemini models continue using Google's native JSON-schema response mode and existing grounding path.

## Validation

- All 31 Gateway checks passed, including hosted-Gemma request shape, image-first ordering, exact schema instructions, local schema validation, fenced-JSON normalization, one bounded repair, and unsupported-grounding rejection.
- The mandatory standalone production-mode build deployed only to the isolated test vault and preserved runtime-owned settings.
- The live Google endpoint accepted the configured API key/project but returned its account-level depleted-prepaid-credits error for model inference. No successful live inference could be claimed, and no production vault or production runtime was accessed.

This release is tested in the isolated Obsidian Plugin Test Vault and is ready for a BRAT pull after publication.
