## 0.6.0

- Adds Apple Intelligence as an iOS-only structured-text provider through TishOS. The plugin writes one explicit `tishos-apple` queue job, opens a strict job-ID-only app route, and waits for the schema-validated result in that same file.
- Durable jobs preserve the caller's stable ID, and ordinary Obsidian queue workers never claim Apple-targeted work. Images and Google Search grounding keep their existing provider routes.
- Supported iOS 26+ devices can use Apple's on-device Foundation Models path without an API key. Private Cloud Compute additionally requires iOS 27 and Apple's managed entitlement in the TishOS app; enabling this provider does not imply that cloud capability is available.
- Settings migrate to schema 3 without discarding existing provider choices. All 34 gateway tests and the production TypeScript build pass in the isolated test vault; production vaults were not accessed or promoted.
