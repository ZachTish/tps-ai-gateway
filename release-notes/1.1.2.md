# TPS AI Gateway 1.1.2

Grok subscription requests now use the official CLI's text prompt-file format. Previously the `.json` extension selected Grok's ACP content-block parser, which rejected the Gateway's plain prompt envelope before inference even after successful sign-in. The request now uses a private `.txt` file with identical content. Prompts remain outside command-line arguments; temporary files are removed after success or failure.

No settings, provider ordering, authentication storage, public API or UI changes. Existing isolated profile, tool restrictions, output bounds, cancellation and timeout behavior remain. Minimum Obsidian version: 1.12.0.
