# TPS AI Gateway 0.8.0

One AI configuration page replaces separate Cloud providers, Device AI, and Diagnostics pages. Choose Cloud (Google AI or OpenAI), On device (Ollama), or TPS routed (TishOS Apple Intelligence), then choose an optional backup directly below. Only relevant provider fields appear. Existing longer backup chains remain intact until explicitly replaced, with an in-place editor for each backup. Diagnostics is a single disclosure.

Ordinary requests now honor the displayed provider order, including Apple after cloud, and Ollama works directly on user-role devices. Pending Apple handoffs do not start duplicate backup work. Native controls restore focus after conditional rendering; compact mobile controls resist theme width overrides and avoid horizontal overflow.

This is a backward-compatible minor feature release. Persisted keys, defaults, credentials, command IDs, and public API signatures are unchanged; no migration is required. Minimum Obsidian: 1.12.0. Existing settings and credentials were preserved.

Limitations: TPS routed uses the existing iPhone/iPad TishOS handoff, which may use Apple Private Cloud Compute or on-device AI. Backups apply to ordinary requests. Durable Apple jobs remain with TishOS; cloud queue workers do not launch Apple backups, and durable Ollama work still requires an eligible Controller worker. Provider-specific callers and the existing synced text queue retain their routing behavior. No live model inference or physical iOS QA was performed for this settings release.

Validation: 42 automated checks passed, including provider transport/schema/privacy, durable queues, primary/backup ordering, pending-handoff safety, control preservation, conditional fields, legacy chains, disabled-provider editing, empty routes, focus/selection, disclosure depth, and mobile CSS. The mandatory separate TypeScript/production build passed and reported test-only deployment. Source and test-runtime artifacts matched byte-for-byte. Reloaded only TPS AI Gateway in the verified Obsidian Plugin Test Vault. Desktop and 600 px settings-window QA covered all modes, all provider editors, backup choices, and Diagnostics using a memory-only settings fixture for selections. The device-local settings and runtime data.json hashes remained unchanged. No credential picker, inference command, or outbound automation was invoked.

Tested in the test vault and ready for the user's manual BRAT pull of numeric tag **0.8.0**. Production was not accessed or installed by this release. User acceptance and production BRAT installation remain separate steps.
