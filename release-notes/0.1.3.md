# TPS AI Gateway 0.1.3

## Release intent

This is the first GitHub release of the existing `0.1.3` plugin for BRAT installation and **Latest**-release tracking. The packaging work adds release metadata without changing shipped runtime behavior, credentials, or queue formats.

## Included behavior

- Schema-validated structured requests across ordered Ollama, OpenAI, and Gemini providers with bounded fallback.
- Guarded capability proposal/execution and Controller-mediated, vault-synced remote jobs for user-role devices.
- Private-repository installation through BRAT with a fine-grained GitHub token limited to **Contents: Read-only**.

## Compatibility

- Minimum Obsidian version: `1.12.0` because cloud credentials use Obsidian SecretStorage.
- Desktop and mobile are supported; loopback Ollama remains desktop-local unless a separately secured endpoint is configured.
- No migration is required from the existing `0.1.3` runtime.

## Validation

- `npm test`: passed `8/8` tests and its nested production build.
- Required separate `npm run build`: passed TypeScript and esbuild production bundling.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; the final source artifacts are byte-identical to the installed test runtime.
- This release candidate is prepared from the test-vault source and has not been promoted to production by this packaging pass.

## Known limitations

- Private BRAT installs require the GitHub token on each device; never store that token in the vault or repository.
- BRAT does not transfer SecretStorage credentials or provider settings between devices.
- User-role remote execution requires an active TPS Controller device and temporarily stores the request text/schema in the synced queue.
- Raw Ollama endpoints should never be exposed directly to the internet.
