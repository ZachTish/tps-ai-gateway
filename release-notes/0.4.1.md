# TPS AI Gateway 0.4.1

## Immediate durable execution

- Persists a durable text request first, then immediately claims and processes it when the requesting device has an eligible configured provider.
- Reads the completed result directly instead of waiting for the background queue scan and polling interval.
- Coalesces local and scanner execution with a per-file in-flight guard so a fast Describe request cannot produce duplicate provider calls.
- Preserves synchronized Controller/other-device processing, abandoned-job recovery, exact durable matching, leases, retention, redacted diagnostics, and device-local credentials.

This is a backward-compatible performance and reliability patch. Existing settings, queue jobs, provider configuration, and public APIs require no migration. Minimum supported Obsidian remains 1.12.0.
