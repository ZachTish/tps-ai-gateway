# TPS AI Gateway 1.1.0

AI Gateway now has its own provider setup: choose a provider, connect, then test that exact connection. Controller is no longer required to reach setup. Optional executable/model overrides, backups and logging stay under one Advanced disclosure.

## Connections

- Gemini subscriptions through official Gemini CLI 0.65.0+ on macOS, with a separate TPS login profile.
- Grok subscriptions through official Grok Build on macOS, subject to account access. Authenticated end-to-end acceptance remains unverified.
- Apple Intelligence through a user-owned Shortcuts Use Model action on supported Apple devices. One explicit foreground callback; no file bridge or polling.
- Ollama and an explicit OpenAI-compatible API endpoint for open models or other providers. OpenCode is a client, not a universal subscription credential; coding-only plans are not presented as general note APIs.
- Existing Google/OpenAI API connections and capability contracts remain supported.

No account login, CLI installation/upgrade, cloud request or model download happens automatically. Gemini/Grok connections do not run on iPhone or forward phone requests through a Mac. API billing remains distinct from consumer subscriptions. Apple computation follows the model selected in the user's shortcut.

## State and safety

Existing device-local settings, unknown fields, backup order, SecretStorage references and disabled states are preserved. Fresh installations start with no selected provider. The retired Apple route remains visibly retired; the new Shortcuts adapter has a separate ID. No queued jobs, vault scan, watcher, cache, maintenance writer or automatic inference was added.

Subscription subprocesses use dedicated profiles, disabled tools/project integrations, shell-free argument arrays, bounded output, terminating deadlines and unload cancellation. Apple callbacks are bounded and matched to an unpredictable request token and vault; cancelled/error/timed-out handoffs never start a backup. Existing schema validation applies to every result. Test connection sends only a synthetic request to the selected provider.

## Validation

- Full declared suite: 46 tests passed, 0 failures. Separate final build passed. Obsidian minimum remains 1.12.0. Unload during a failed request cannot start a backup or a new diagnostic.
- Explicit deployment and reload in Obsidian Plugin Test Vault confirmed loaded version 1.1.0. Sync remained disabled.
- Installed provider matrix checked all seven choices and the retired route; one disclosure, no nested disclosures. Native UI inspection covered subscription setup/focus restoration, Advanced controls, Apple setup, compatible API fields and Ollama/legacy backup controls. An input-overlap issue found during inspection was corrected and rechecked.
- Provider selection and exact-provider Test action exercised through a nonpersisting settings fixture; the provider request boundary was stubbed. Existing saved settings hash stayed unchanged, as did private runtime files. The plugin's original disabled/unloaded state was restored.
- Unit coverage includes mobile platform guards and responsive CSS; the available native settings window was 900 CSS pixels wide. Physical iPhone/mobile visual acceptance is unverified.
- Network/model adapters are mocked. Real synthetic subprocesses test literal stdin, output limits, failures, timeout and cancellation. Actual Gemini/Grok account sign-in, provider eligibility and Apple model inference remain unverified. The installed Gemini CLI was too old for isolated profiles; it was not upgraded. Grok Build was not installed.
- Production was not accessed or deployed for this release. Published artifacts are available for a deliberate BRAT update; user acceptance is still required before a production-ready claim.
